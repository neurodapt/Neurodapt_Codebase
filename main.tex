\begin{abstract}
 We present Neurodapt, a framework for long term memory retention oriented rewriting that combines a Transformer-based clause boundary predictor, a memory-ranking module, and a GRPO fine-tuned LLM. The rewriting objective combines three components: improving the Memory Ranker score, preserving semantic meaning with an similarity measure, and dynamically enforcing a bounded length constraint.
\end{abstract}

\begin{IEEEkeywords}
Large Language Models, Reinforcement Learning, Educational Technology, Memory Modeling, Cognitive Computing
\end{IEEEkeywords}

\section{Introduction}

LLM automate text generation but do not focus on whether important information will be retained by the reader in the long term. A rewrite can therefore be faithful in meaning while still changing the parts that can help the user retain the information. We propose \textbf{Neurodapt}, an approach to memory-oriented text rewriting. Its main contributions are:
\begin{enumerate}
\item A clause-boundary prediction module that uses a Transformer to estimate the probability of each token being a clause boundary.
\item A Transformer-based Memory Ranker trained from narrative retelling data to estimate relative clause memorability.
\item An LLM fine-tuned with GRPO to rewrite clauses toward higher memory-retention scores produced by the Memory Ranker.
\end{enumerate}

\section{Related Work}

LLMs are now widely used for rewriting, summarization, and educational content generation \cite{zhang2023summit}. Much of this work emphasizes fluency, semantic similarity, or downstream task performance rather than the likelihood that particular information will be retained \cite{nakatani2022}. This distinction is important because a fluent rewrite can still alter the organization and cues that support later retrieval \cite{roit2023}.

Research on narrative memory offers a useful source of supervision for this problem. Georgiou et al. studied recall of meaningful narratives at scale and reported relationships between clause-level properties and human recall probabilities \cite{georgiou2025}. Cognitive accounts such as ACT-R describe retrieval in terms of activation, context, and interference \cite{bothell2021}, while spaced-repetition models focus on review history and forgetting \cite{settles2016}. Neurodapt differs in emphasis: instead of only modeling memory after information is presented, it uses memory-related signals to inform how the information is rewritten.

Embedding-based measures such as BERTScore are established tools for assessing semantic preservation \cite{zhang2019}. Neurodapt builds on this idea by combining semantic preservation with clause-level segmentation, narrative-based memorability estimation, and a reinforcement-learning formulation.

\section{Proposed Framework}

Given an input text, the framework first segments the text into individual clauses using the clause segmentation module. Each clause is then assigned a relative memory-retention score by the Memory Ranker, which estimates how strongly the clause is expected to contribute to the retention of the overall text.

Based on these scores, a target clause is selected for rewriting by the user. The target clause is provided to the rewriting LLM together with its surrounding clauses as contextual information. The rewriting LLM is fine-tuned using Group Relative Policy Optimization (GRPO), with the Memory Ranker providing the reward signal during training. This encourages the model to generate rewrites that achieve higher estimated memory-retention scores while remaining conditioned on the original context.

\section{Clause Segmentation}

\subsection{Motivation and Problem Formulation}

We use clauses as the basic unit of memory analysis because they provide a linguistically meaningful unit between individual tokens and complete sentences. A clause can express an event, action, state, or proposition that can be treated as a distinct unit of information. In contrast, a sentence may contain multiple such propositions, making sentence-level analysis relatively coarse for estimating the contribution of individual textual units. Clause segmentation therefore provides a practical intermediate representation between token-level and sentence-level analysis \cite{seyfried2024}.

Given a sentence $S=(w_1,w_2,\ldots,w_n)$, the objective of the segmentation module is to predict whether each token position corresponds to the beginning of a new clause. The task is formulated as binary sequence prediction, where each token is assigned a boundary label $y_i\in\{0,1\}$.

\subsection{HCA Dataset and Data Preparation}

The clause boundary predictor is trained using the English HCA corpus (\texttt{eng.hca.amr}) provided by HCASeg \cite{yu2023}. The corpus is annotated for clause-level segmentation and is distributed in CoNLL-U format, with clause boundaries indicated by \texttt{BeginSeg=Yes} in the \texttt{MISC} field. We use the original training, development, and test partitions supplied with the dataset.

After preprocessing, the training, validation, and test sets contain 17,885, 740, and 751 sentences, respectively. The corresponding average sentence lengths are 24.59, 27.51, and 28.39 words. The average clause length is 8.44 words in the training set, 9.31 words in the validation set, and 9.23 words in the test set. The distribution of clause lengths in the training set is concentrated primarily between 3 and 12 words, with shorter clauses occurring less frequently and a smaller number of clauses exceeding 20 words.

The boundary labels are converted into a binary sequence for each sentence. The training set contains 34,873 boundary positions and 447,017 non-boundary positions, corresponding to approximately 7.8\% boundary tokens. The validation and test sets contain 1,482 and 1,599 boundary positions, respectively. This distribution results in a substantially larger number of non-boundary than boundary positions, which is considered when evaluating the boundary prediction model.

Because the annotations are defined over the original tokenization while the model uses BERT WordPiece tokenization, the clause boundary labels are aligned with the resulting subword tokens using character offsets. This prevents subword tokenization from shifting the annotated boundary positions. Padding positions introduced during batching are excluded from the training loss and evaluation.

\subsection{Contextual Representation and Model Architecture}

The segmentation model uses \texttt{bert-base-uncased} to obtain contextual representations for the input tokens. For each token position $i$, BERT produces a representation $h_i\in\mathbb{R}^{768}$. We additionally compute a sentence-level representation by mean-pooling the token representations. Let this representation be $h_S\in\mathbb{R}^{768}$. The sentence representation is concatenated with every token representation:

\begin{equation}
x_i=[h_i;h_S]\in\mathbb{R}^{1536}.
\end{equation}

Providing the sentence-level representation alongside the token representation gives the boundary predictor access to both local contextual information and information about the sentence as a whole.

The resulting sequence of representations is projected from 1536 to 384 dimensions and passed through a four-layer Transformer encoder with four attention heads, a feed-forward dimension of 1536, and dropout of 0.2. The projection is given by $z_i=W_px_i+b_p$, where $W_p\in\mathbb{R}^{384\times1536}$ and $b_p\in\mathbb{R}^{384}$. The resulting contextual representations are then used by a linear prediction layer to estimate the likelihood that each token marks a clause boundary. The complete architecture and information flow of the module are shown in Fig.~\ref{fig:clause_architecture}.

\subsection{Boundary Prediction and Training}

For each token representation $z_i$, a linear layer produces a boundary logit $l_i$. The logit is converted into a boundary probability using the sigmoid function. A token is predicted to mark the beginning of a clause when its probability exceeds a decision threshold $\tau$. The model is trained using binary cross-entropy over the non-padding token positions. AdamW is used as the optimizer with a learning rate of $10^{-4}$ and a batch size of 4. Training is performed for up to 30 epochs, with the checkpoint achieving the lowest development-set loss retained for evaluation.

The decision threshold is calibrated separately after training using the development set. A threshold of $\tau=0.39$ is selected and subsequently fixed for test-set evaluation and inference.

\subsection{Clause Reconstruction and Post-Processing}

The predicted boundary sequence is converted into an ordered clause sequence $C=(c_1,c_2,\ldots,c_k)$ by grouping consecutive tokens between predicted boundaries. Each clause is then processed as follows:

\begin{itemize}
\item \textbf{Merge WordPiece subwords:} remove the continuation marker \texttt{\#\#}.
\item \textbf{Normalize text:} remove spaces before punctuation, around slashes and hyphens, and inside contractions.
\item \textbf{Attach punctuation fragments:} merge punctuation-only clauses, such as \texttt{,} or \texttt{.}, with the preceding clause.
\item \textbf{Merge isolated words:} append a single-word fragment to the preceding clause.
\item \textbf{Remove short fragments:} repeatedly merge clauses containing fewer than four whitespace-delimited tokens. A short first or last clause is merged with its only neighbor.
\item \textbf{Resolve intermediate fragments:} merge a short clause with the smaller neighboring clause, except when the left neighbor ends in a period; in that case, merge it with the right neighbor.
\end{itemize}

The resulting clauses are contiguous, readable, and passed to the Memory Ranker for clause-level memory-retention analysis.

\section{Memory Ranking Module}

After segmentation, the memory ranker module estimates the relative memorability of individual clauses using Breithaupt narrative recall data.

\subsection{Narrative Recall Data}

The memory-ranking model is trained using the Breithaupt narrative dataset \cite{he2023}, which contains an original story and three subsequent human retellings. We pass the original story and each retelling through the trained clause segmenter to obtain ordered clause sequences.

For an original story, let

\begin{equation}
C^{(o)}=(c^{(o)}_1,c^{(o)}_2,\ldots,c^{(o)}_N)
\end{equation}

denote its original clauses and let

\begin{equation}
C^{(g)}=(c^{(g)}_1,c^{(g)}_2,\ldots,c^{(g)}_{M_g})
\end{equation}

denote the clauses in retelling $g$, where $g\in\{1,2,3\}$.

\subsection{Clause-Level Recall Matching}

Each clause is represented by a normalized 768-dimensional \texttt{all-mpnet-base-v2} embedding. For an original clause $c^{(o)}_i$, we compute cosine similarity against each clause in each retelling, and the strongest match becomes the retelling-level score:

\begin{equation}
r_i^{(g)}
=
\max_{j\in C^{(g)}}e_i^\mathsf{T}e_j^{(g)},
\end{equation}

where $e_i$ and $e_j^{(g)}$ are normalized clause embeddings.

Then the three retelling scores are summed:

\begin{equation}
r_i =
\sum_{g=1}^{3}r_i^{(g)}.
\end{equation}

A clause therefore receives a higher score when its content is reflected in the human retellings. 

\subsection{Within-Story Normalization}

The goal is to compare clauses within each story rather than compare absolute scores across different stories. The retelling scores are min--max normalized within each story. If a story contains only one clause, or all clauses have the same score, every clause is assigned the neutral target value $0.5$.

This normalization preserves the within-story ordering while reducing the influence of differences in the absolute embedding-similarity scale.

\subsection{Transformer-Based Memory Ranker}

\begin{figure}[H]
\centering
\includegraphics[width=\columnwidth,height=2.2in,keepaspectratio]{Fig3.png}
\caption{Training and inference pipeline of the Memory Ranking Module.}
\label{fig:memory_ranker}
\end{figure}

The normalized retelling scores are used as targets for a Transformer-based Memory Ranker. Each 768-dimensional clause embedding $x_i$ is first projected into a 256-dimensional hidden space:

\begin{equation}
z_i=W_px_i+b_p.
\end{equation}

A learned positional embedding captures the location of each clause in sequences of up to 512 clauses. The resulting sequence is processed by two Transformer encoder layers with four attention heads, a feed-forward dimension of 1024, GELU activation, and dropout of 0.1. A two-layer MLP with ReLU and dropout 0.1 produces one unbounded logit per clause; sigmoid is applied for probability-scale predictions.

\subsection{Ranking Objective}

Because the primary goal is relative ranking within a story, the training objective combines binary cross-entropy with a margin-ranking loss:

\begin{equation}
\mathcal{L}=0.5\mathcal{L}_{\mathrm{BCE}}+0.5\mathcal{L}_{\mathrm{rank}},
\end{equation}

where the pointwise term is binary cross-entropy with logits, and, for unequal target scores, the pairwise term uses margin 0.2. The pairwise losses are averaged within each story and then across the batch. Variable-length stories are padded and passed with a key-padding mask; tied target pairs are excluded from the ranking loss. Sigmoid is applied to raw model logits for probability-scale inference, not in the pairwise loss.

\subsection{Training and Evaluation}

The Memory Ranker is trained with AdamW at a learning rate of $10^{-4}$, batch size 8, and a maximum of 50 epochs. A ReduceLROnPlateau scheduler halves the learning rate after two non-improving validation epochs, down to a minimum of $10^{-6}$. Stories are shuffled deterministically using seed 42 and split by story into 70\% training, 10\% validation, and the remaining test set (integer truncation determines the exact counts). Early stopping monitors validation loss with patience of epochs, and the lowest validation loss checkpoint is saved.

\section{Reinforcement Learning Pipeline}

The RL reward has three normalized components: (1) a Memory Ranker score for memorability, (2) an MPNet-based semantic-similarity score comparing the source target clause with its rewrite, and (3) a length-compliance score. Unless otherwise stated, the BERT-based Memory Ranker configuration is the default ranker used for clause scoring, dataset construction, inference, and reward computation. The training data are produced from 50-word windows with stride 50. The existing clause segmenter and Memory Ranker score each window; interior clauses are selected in center-out order as target examples. The prompt instructs the model to preserve the target meaning, avoid adding information or borrowing from other clauses, produce one sentence, and keep the rewrite between 70\% and 150\% of the original target's word count. Up to 20,000 valid examples are selected using seed 42 by default.

The policy is the local Qwen2.5-0.5B-Instruct model, trained for one epoch with TRL's GRPO trainer. The run uses 4-bit NF4 quantization with double quantization, FP16 computation, and LoRA adapters (rank 8, alpha 16, dropout 0.05) on the query, key, value, and output projections. The per-device batch size is 2, gradient accumulation is 8, four completions are sampled per prompt, the learning rate is $5\times10^{-6}$, and the maximum prompt and completion lengths are 256 and 48 tokens. The saved run contains 5,000 training steps and reaches epoch 1.

For each candidate, the reward scorer embeds the original target and rewrite with normalized MPNet embeddings. The original embedding is cached and rewrite embeddings are computed in batches; the same embedding pair is reused for both the Memory Ranker and semantic-similarity components. Let $\Delta=s_{\mathrm{rewrite}}-s_{\mathrm{original}}$, where each $s$ is the Memory Ranker's sigmoid output, and let $L_o$ and $L_w$ be the original and rewritten word counts. The ranker component is normalized as $m=(\Delta+1)/2$, and the cosine-similarity component is normalized as $q=(1+\cos(e_o,e_w))/2$. Both therefore have the common base range $[0,1]$.

The length component uses a fixed validity interval rather than a changing length limit:
\begin{equation}
\ell=\begin{cases}
1, & 0.7L_o\leq L_w\leq 1.5L_o,\\
0, & \text{otherwise.}
\end{cases}
\end{equation}

The weighted base reward is
\begin{equation}
R_{\mathrm{base}}=w_m m+w_\ell\ell+w_q q,
\end{equation}
where training begins with $(w_m,w_\ell,w_q)=(1/3,1/3,1/3)$. Empty outputs receive $-2.5$. Outputs outside the 70--150\% interval retain a separate rejection penalty, which is the minimum of the weighted reward and $-1.5$ minus a proportional excess-length term. This preserves a strong hard constraint without allowing the penalty scale to distort the normalized component weights.

The length weight adapts during training while the 70--150\% interval remains fixed. Statistics are accumulated over a window of 32 non-empty candidates. If at least 10\% of candidates violate the interval, or at least 50\% lie within 5\% of either boundary, the length weight increases by 0.05, taking weight equally from the Memory Ranker and similarity components. If a window has no violations and no more than 25\% boundary-near candidates, the length weight decreases by 0.05, transferring that weight equally to the other two components. The length weight is bounded below by 0.04 and above by its initial value of $1/3$. Thus the objective can move toward, for example, approximately 48\% Memory Ranker, 4\% length, and 48\% similarity after stable length compliance, while restoring length pressure if the policy begins to exceed or crowd the fixed limit.

\subsubsection{Experiment 3: Comparison with Existing Resources and Models}

To the best of our investigation, we did not identify an existing publicly available dataset that provides sufficiently large-scale, clause-level human memorability or retention annotations for narratives in a form directly compatible with the proposed task. Existing narrative-memory datasets differ substantially in their experimental design, annotation granularity, or number and type of narrative stimuli. For example, existing work has investigated memory through large-scale narrative retellings, while other datasets provide participant recalls for a small number of narrative stimuli rather than clause-level retention annotations. Consequently, direct cross-dataset evaluation would require substantial changes to the target construction and would not constitute a controlled evaluation of the same prediction task.

Similarly, we did not identify an existing model that performs the same clause-level relative memory-retention ranking task using comparable supervision. We therefore do not report a direct comparison against an external memorability-ranking baseline. Instead, model validity is evaluated through held-out story-level testing and controlled ablation experiments examining the contribution of the ranking objective, contextual modeling, positional information, normalization strategy, and semantic representation. These experiments are intended to establish whether the proposed architecture and target construction contribute meaningfully to the observed ranking performance.

The remaining generated diagnostics and parsed metric CSV are retained as supplementary result assets. The small average score change motivates evaluation on a larger held-out prompt set and direct human-retention measurements.

\section{Discussion and Conclusion}


These results should be interpreted as evidence of optimization toward the learned memory objective rather than direct evidence of improved human memory. The Memory Ranker is itself a learned proxy for retention, and the current evaluation does not include human recall measurements. Nevertheless, the results demonstrate the feasibility of using a learned clause-level memory signal as a reward for targeted LLM rewriting.

Overall, Neurodapt provides a complete pipeline from clause segmentation and memory estimation to reinforcement-learning-based rewriting. Future work should evaluate generated rewrites through controlled human memory experiments and investigate whether improvements in the learned memory score translate to measurable improvements in actual information retention.
